# nicodamian.com

Personal site of Nicolás Damián Sadofschi. One static page, built with Astro and Tailwind, hosted on GitHub Pages.

## Run it

Requires Node 24.16 or newer.

```sh
npm ci
npm run dev      # http://localhost:4321
npm run build    # type check, build, then the leak scan
npm run preview  # serve the built site
npm test         # unit tests
```

## Edit the content

All text lives in `src/data/`. Nothing else needs to change for a content update.

| File | What it holds |
| --- | --- |
| `profile.ts` | Name, tagline, about, origin story, hero facts |
| `experience.ts` | Roles and education |
| `credentials.ts` | Certifications (in order of importance) and skills |
| `projects.ts` | Project cards |
| `beyond.ts` | Interests and contact channels |

Wrap anything still unconfirmed in `todo('…')`. It renders as a visible marker, `npm run todos` lists it, and `STRICT_CONTENT=1 npm run todos` fails if any remain.

## How it is put together

- `src/components/` holds one component per section; `src/layouts/Base.astro` holds the page shell and the only client script.
- `src/lib/terminal.ts` is the command interpreter behind the hero terminal. It is pure and unit-tested; output is written to the page as text, never as HTML.
- The Content Security Policy is a `<meta>` tag generated by Astro with hashes, because GitHub Pages cannot send custom headers. No inline handlers, no third-party requests, fonts are self-hosted.
- `scripts/check-leaks.mjs` fails the build if a private hostname, IP address, secret-shaped string or stray email reaches the source or `dist/`. Extra private terms go in `.leak-denylist.local`, one per line; that file is git-ignored.
- `npm run og` regenerates `public/og.png`; `npm run shots` takes screenshots and fails on console errors, CSP violations, third-party requests or horizontal overflow.
